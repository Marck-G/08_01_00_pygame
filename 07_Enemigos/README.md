# Sesión 7: Enemigos y Obstáculos

**Objetivo:** Añadir enemigos y obstáculos al juego, con interacciones que afectan al jugador.

## Contenidos

* Creación de enemigos móviles
* Creación de obstáculos fijos
* Colisiones jugador-enemigos y jugador-obstáculos
* Integración con vidas y pantalla de Game Over

## Detalles

1. **Enemigos:**

   * Definir movimiento horizontal o patrullaje.
   * Detectar colisión con el jugador y reducir vidas.
   * Animaciones básicas si se disponen de sprites.

2. **Obstáculos:**

   * Objetos fijos que generan daño o bloquean el paso.
   * Detectar colisión con jugador y reducir vidas o reiniciar posición.

3. **Integración con el sistema de vidas:**

   * La colisión con enemigos/obstáculos disminuye las vidas.
   * Si las vidas llegan a cero, se cambia a la escena de Game Over.

4. **Ventajas:**

   * El juego gana dinamismo y desafío.
   * Permite introducir patrones de enemigos y obstáculos variados.

**Resultado esperado:**

* El jugador debe esquivar o derrotar enemigos y obstáculos.
* La mecánica de vidas y Game Over se mantiene funcionando.
* El nivel se vuelve más interactivo y retador.
